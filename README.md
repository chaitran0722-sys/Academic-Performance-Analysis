# 📊 Academic Performance Analysis (Excel Project)

🔍 Project Overview

This project analyzes my academic performance across 10th, Diploma, and Engineering using Excel.

🛠 Tools Used

* Microsoft Excel
* Pivot Tables
* Charts

📊 Data Description

The dataset includes:

* Education levels (10th, Diploma, Engineering)
* Overall percentage performance

📈 Key Insights

* Academic performance improved from 10th (55.84%) to Engineering (72.8%)
* Significant improvement during Diploma phase
* Engineering shows highest overall performance
